# UI Copy Policy

## Goal

Keep visible app text natural, consistent, and aligned with Brazilian Portuguese product writing.

## Capitalization

Use sentence case for visible UI text in Portuguese.

Examples:

- `Saldo projetado`
- `Pagamentos do mês`
- `Sobra ou falta por mês`
- `Comprometimento do salário`
- `Próximo vencimento`
- `Contas cadastradas`
- `Planejamento mensal`

Do not use English-style title case for Portuguese UI copy.

Avoid:

- `Saldo Projetado`
- `Pagamentos do Mês`
- `Sobra ou Falta por Mês`

Exceptions:

- App names and brand names keep their official capitalization, such as `Cycle12 Finance`.
- Technical acronyms keep their normal capitalization.
- Navigation tabs may use short labels, such as `Resumo`, `Gráficos`, `Planejar`, `Contas`, and `Ajustes`.

## Action Labels

Prefer direct, compact action labels.

When a label starts with `Ver`, remove `Ver` and keep the object or destination name when the meaning remains clear.

Examples:

- `Ver detalhes` -> `Detalhes`
- `Ver valor` -> `Valor`
- `Ver pagamentos` -> `Pagamentos`

Use verbs when they represent the actual operation and cannot be removed without losing meaning.

Examples:

- `Adicionar conta`
- `Fazer backup`
- `Restaurar backup`
- `Limpar tudo`
- `Cancelar`
- `Confirmar`

## Tone

Prefer practical, concise, user-facing language.

Avoid explanatory copy inside the app unless it helps the user complete a financial task or understand a destructive action.
