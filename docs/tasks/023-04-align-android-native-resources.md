# Task 023-04 - Align Android Native Resources

## Spec

`docs/specs/023-app-icon-and-splash-alignment.md`

## Plan

`docs/plans/023-app-icon-and-splash-alignment-plan.md`

## Goal

Refresh or align generated Android resources so the installed app matches the Expo branding configuration.

## Steps

1. Update Android launcher foreground resources under `android/app/src/main/res/mipmap-*/`.
2. Update Android launcher round and default icon resources when generated by the Expo/Android toolchain.
3. Verify adaptive icon XML files reference the foreground and background resources correctly.
4. Update Android splash logo resources under `android/app/src/main/res/drawable-*/`.
5. Update Android color/style resources when the selected icon or splash background changes.
6. Confirm native resources no longer contain the old calendar/coins illustration.
7. Remove `assets/novo/` only after generated assets under `assets/` and Android resources are aligned.

## Acceptance Criteria

- Installed Android launcher icon uses the selected `12` logo.
- Native launcher foreground resources no longer show the old calendar/coins illustration.
- Native splash resources match the selected splash direction.
- Android adaptive icon XML remains valid.
- Android splash styles remain valid.
- Temporary `assets/novo/` folder is removed after successful asset promotion.

## Implementation Notes

- Replaced native launcher foreground resources with generated PNG resources.
- Replaced native launcher fallback and round icon resources with generated PNG resources.
- Replaced native splash logo resources with generated PNG resources.
- Updated native icon and splash background colors to `#F5F7FA`.
- Removed the temporary `assets/novo/` folder after promotion.
