# Task 015-03 - Add Monthly Adjustment UI

Status: Completed

## Spec

`docs/specs/015-monthly-value-adjustments.md`

## Plan

`docs/plans/015-monthly-value-adjustments-plan.md`

## Goal

Add compact add and subtract controls to each monthly value row in the planning editor.

## Steps

1. Add `+` and `-` controls beside each monthly value input.
2. Show a compact adjustment input for the selected row and operation.
3. Provide confirm and cancel actions.
4. Keep the layout usable on narrow mobile screens.

## Acceptance Criteria

- Users can add an adjustment from a row.
- Users can subtract an adjustment from a row.
- The adjustment input can be cancelled.
- The row layout avoids accidental horizontal overflow.
