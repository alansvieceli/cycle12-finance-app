# Task 022-02 - Add Typography Tokens

## Goal

Create centralized typography tokens for app text roles.

## Scope

- Add `src/theme/typography.ts`.
- Export semantic token objects for font size, line height, and weight.
- Keep tokens simple and TypeScript-friendly.

## Acceptance Criteria

- Typography tokens can be imported by components.
- Tokens cover titles, cards, amounts, body text, labels, buttons, tabs, captions, and inputs.
